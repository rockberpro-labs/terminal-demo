# terminal-demo

Animated SVG demos of your terminal sessions, generated by [Claude Code](https://claude.com/claude-code). Scripted and reproducible, so you can regenerate the demo whenever your CLI changes.

> [!WARNING]
> **`asciinema` is required.** This plugin does not install it, and the skill cannot record a demo without it. Install it first (e.g. `sudo apt install asciinema`, `brew install asciinema`, or `pipx install asciinema`) and check with `asciinema --version`. See [Requirements](#requirements).

## Install

In Claude Code:

```
/plugin marketplace add rockberpro-labs/terminal-demo
/plugin install terminal-demo@rockberpro-labs
```

To update later:

```
/plugin marketplace update rockberpro-labs
```

## Requirements

The plugin does not install these for you:

- **[`asciinema`](https://asciinema.org/) 2.4.0 or newer** (needs `--cols/--rows`). Required: without it no demo can be recorded.
- [`bun`](https://bun.sh/) **or** [Node.js](https://nodejs.org/) (the skill runs `svg-term-cli` through `bunx`, or `npx` if bun isn't installed)
- `bash`, `sed`

## Usage

Ask Claude for a demo, for example:

- "Record a demo of my git aliases for the README"
- "Regenerate the terminal demo"

The skill is `generate`, run as `/terminal-demo:generate`. It will:

1. Build a sandbox outside your project, with a local bare repo as `origin` if the demo pushes.
2. Isolate git config so your identity, hooks and system config stay out of the recording.
3. Play a `script.txt` (one command per line, optional `# comment`) with simulated typing.
4. Record with `asciinema`, sanitize the cast, and convert it to SVG.
5. Add the `<img>` to your README.

See [`skills/generate/SKILL.md`](skills/generate/SKILL.md) for the full pipeline and gotchas.

## Manual install (without the plugin system)

Copy the skill folder:

```bash
git clone https://github.com/rockberpro-labs/terminal-demo
cp -r terminal-demo/skills/generate ~/.claude/skills/
```
